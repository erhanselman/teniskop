# Türk Tenisciler

Türkiye tenisinde farklı dönemlerde uluslararası turnuvalarda mücadele eden ve önemli başarılar kazanan birçok sporcu vardır.

| İsim | Kısa Bilgi |
| --- | --- |
| Marsel İlhan | Türkiye tenisinde erkekler kategorisinde önemli uluslararası başarılara imza atmıştır. |
| Çağla Büyükakçay | Grand Slam ana tablosunda yer alan ve WTA düzeyinde başarılar kazanan önemli Türk teniscilerdendir. |
| İpek Soylu | Çiftler kategorisindeki başarılarıyla tanınan Türk teniscidir. |
| Cem İlkel | ATP turnuvalarında Türkiye'yi temsil eden başarılı erkek teniscilerdendir. |
| Zeynep Sönmez | Yeni nesil Türk tenisciler arasında yükselen isimlerden biridir. |
| Pemra Özgen | Uzun yıllar Türkiye'yi uluslararası turnuvalarda temsil eden deneyimli teniscilerdendir. |
| Altuğ Çelikbilek | ATP düzeyinde mücadele eden başarılı Türk erkek teniscilerdendir. |
| İpek Şenoğlu | Grand Slam çiftler ana tablosunda yer alan ilk Türk teniscilerden biri olarak bilinir. |
